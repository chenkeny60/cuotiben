GS-001 拉格朗日中值定理与不等式放缩 错因 · 方法选择 已掌握 复习 · 2026-11-19 展开详情 ▾收起 ▴
📌 原题

设 0<a<b，证明不等式 2a/(a²+b²) < (ln b − ln a)/(b−a)。

❌ 我的错误步骤

第 1 步：同乘 (b − a)，又令 t = b/a 换元 —— 变形正确。 第 2 步：改走辅助函数路线，写了几行又划掉。 第 3 步：改走拉格朗日路线，写到 1/ξ = (ln b − ln a)/(b − a) 就停了。 ✗ 断点：第 3 步之后没接上——要用 ξ < b 放缩 1/ξ，才能得到下界。

✅ 正确解法
对 ln x 用拉格朗日→差商 = 1/ξ→a²+b² ≥ 2ab 放缩→取倒数得证

证明： 设 f(x) = ln x，x ∈ [a, b]。 f 在 [a, b] 上连续、在 (a, b) 内可导，由拉格朗日中值定理， 存在 ξ ∈ (a, b)，使 (ln b − ln a)/(b − a) = f′(ξ) = 1/ξ。 由 (a − b)² ≥ 0，得 a² + b² ≥ 2ab， 两边同除以 2a（> 0）：(a² + b²)/(2a) ≥ b > ξ > 0。 取倒数：1/ξ > 2a/(a² + b²)。 代回即得 (ln b − ln a)/(b − a) > 2a/(a² + b²)。证毕。

🔑 关键方法

差商用拉格朗日换成 1/ξ，再用 a² + b² ≥ 2ab 放缩。

💡 需要记忆的结论

a² + b² ≥ 2ab；正数取倒数，不等号方向翻转。

🔁 变式题（先闭卷做它）待作答

设 0<a<b，证明：(b−a)/(2√b) < √b − √a < (b−a)/(2√a)。

GS-002 中值定理（介值定理、罗尔定理） 错因 · 方法选择 未掌握 复习 · 2026-10-30 展开详情 ▾收起 ▴
📌 原题

设 f(x) 在 [0,2] 上连续、在 (0,2) 内可导，且 f(0)+f(1)=4，f(2)=2。证明：∃ξ∈(0,2)，使 f′(ξ)=0。

❌ 我的错误步骤

第 1 步：两次用拉格朗日，算出 f′(a₁) = (f(1) − 2)/2、f′(a₂) = 2 − f(1)； ✗ 却把比值写成 f′(a₁)/f′(a₂) = −2（应为 −1/2），分子分母写反。 第 2 步：由 f′(a₁) 与 f′(a₂) 异号，直接推出 ∃ξ 使 f′(ξ) = 0； ✗ 介值定理只适用于连续函数，f′ 不一定连续，这一步不成立。 第 3 步：结论区间写成 (0, 1)，题目要求的是 (0, 2)。

✅ 正确解法
看 f(1) 是否 = 2→介值定理找等值点 c→罗尔定理收官

证明： 情形 1：f(1) = 2。 由 f(0) + f(1) = 4 得 f(0) = 2 = f(1)， 在 [0, 1] 上用罗尔定理，得 ξ ∈ (0, 1) ⊂ (0, 2)，f′(ξ) = 0。 情形 2：f(1) ≠ 2。 f(0) = 4 − f(1)，f(0) 与 f(1) 分居 2 的两侧， 由介值定理（f 在 [0, 1] 上连续），存在 c ∈ (0, 1)，使 f(c) = 2 = f(2)， 在 [c, 2] 上用罗尔定理，得 ξ ∈ (c, 2) ⊂ (0, 2)，f′(ξ) = 0。 两种情形都得证。证毕。

🔑 关键方法

先用介值定理找等值点，再用罗尔定理。

💡 需要记忆的结论

介值定理不能用在导函数 f′ 上（f′ 不一定连续）。

📌 原题

求不定积分 ∫ 1/(2+cos x) dx。（宋浩专升本数学课程板书题，编号 (2)；提交图为老师板书截图，板书解法做到换元前一步未写完）

❌ 我的错误步骤

未提供本人步骤（提交的是老师板书截图）。 卡点：入手方法——想不到先用二倍角把 cos x 化掉再换元。

✅ 正确解法

解： cos x = 2cos²(x/2) − 1， 分母 2 + cos x = 2cos²(x/2) + 1。 再用 1 = sin²(x/2) + cos²(x/2)： 分母 = sin²(x/2) + 3cos²(x/2) = cos²(x/2) · [3 + tan²(x/2)]。 原积分 = ∫ sec²(x/2) / [3 + tan²(x/2)] dx。 令 u = tan(x/2)，du = (1/2)sec²(x/2) dx， 原积分 = ∫ 2/(3 + u²) du = (2/√3) arctan(u/√3) + C。 回代：∫ dx/(2 + cos x) = (2/√3) arctan( tan(x/2)/√3 ) + C。

🔑 关键方法

分母含 a + cos x：先二倍角化成半角平方，再凑 sec²(x/2) 配 tan(x/2) 换元（或万能代换一步到位）。

💡 需要记忆的结论

∫ dx/(a² + x²) = (1/a) arctan(x/a) + C。

GS-004 不定积分（部分分式与拆项） 错因 · 方法选择 未掌握 复习 · 2026-11-09 展开详情 ▾收起 ▴
📌 原题

求不定积分 ∫ (x²−1−x)/(x²(x+1)) dx。（选择题：A. ln|x+1|+C；B. ln|x|−1/x+C；C. ln|x+1|−1/x+C；D. ln|x+1|+1/x+C；正确答案 D）

❌ 我的错误步骤

未提供本人步骤。 卡点（本人自述）：分子拆项——x² − x − 1 没拆成 x² − (x + 1)，入不了手。

✅ 正确解法

解： 分子拆项：x² − x − 1 = x² − (x + 1)。 被积函数 = x²/[x²(x + 1)] − (x + 1)/[x²(x + 1)] = 1/(x + 1) − 1/x²。 逐项积分：∫ = ln|x + 1| + 1/x + C。选 D。

🔑 关键方法

分子按分母的因子拆：分母有 x²(x + 1)，就把分子拆成 x² 与 (x + 1) 的组合，约分后逐项积。

💡 需要记忆的结论

∫ dx/x² = −1/x + C（负号最容易丢）。

🔁 变式题（先闭卷做它）待作答

求不定积分 ∫ (2x+3)/(x(x+1)) dx。

📌 原题

【真题 9】设函数 f(x) 在 [0, 1] 上连续，且 f(x) > 0，试证明：方程 ∫₀ˣ f(t)dt + ∫₁ˣ 1/f(t) dt = 0 在 (0, 1) 内有且只有一个根。（宋浩专升本数学课程板书题；提交图为老师板书截图）

❌ 我的错误步骤

未提供本人步骤（提交的是老师板书截图；备注：5分钟内没想出来）。 卡点：入手方法——想不到把方程左边设为辅助函数 g(x)，再用零点定理与单调性论证存在唯一根。

✅ 正确解法

证明： 设 g(x) = ∫₀ˣ f(t)dt + ∫₁ˣ 1/f(t) dt，x ∈ [0, 1]。 g 在 [0, 1] 上连续。 g(0) = ∫₁⁰ 1/f(t) dt = −∫₀¹ 1/f(t) dt < 0（f > 0，故 1/f > 0）。 g(1) = ∫₀¹ f(t) dt > 0。 由零点定理，存在 x₀ ∈ (0, 1)，使 g(x₀) = 0。 g′(x) = f(x) + 1/f(x) > 0，g 在 [0, 1] 上严格单调递增，根至多一个。 故方程在 (0, 1) 内有且只有一个根。证毕。 （板书核对：板书 g(0)、g(1)、g′(x) 三步均正确，只缺最后“零点定理＋单调性”收尾一句。）

🔑 关键方法

方程求根先设辅助函数：把方程左边看成 x 的函数，再算端点值、求导看单调性；存在性用零点定理，唯一性用单调性。

💡 需要记忆的结论

f > 0 时 ∫₀¹ f(t)dt > 0、∫₀¹ 1/f(t)dt > 0；变限积分求导 (∫ₐˣ f(t)dt)′ = f(x)。

🔁 变式题（先闭卷做它）待作答

GS-006 定积分（换元法证明积分等式） 错因 · 方法选择 未掌握 复习 · 2026-11-14 展开详情 ▾收起 ▴
📌 原题

【真题 29】若 f(x) 在 [0, 1] 上连续，(1) 证明 ∫₀^π x f(sin x) dx = π/2 ∫₀^π f(sin x) dx。（只提交了第 (1) 问；提交图为老师板书截图，板书开头与结尾不在画面内）

❌ 我的错误步骤

未提供本人步骤（提交的是老师板书截图；备注：这题根本做不来）。 卡点：入手方法——想不到用 x = π − t 换元，利用 sin(π − t) = sin t 把积分里的 x 换掉。

✅ 正确解法

证明： 记 I = ∫₀^π x f(sin x) dx。 令 t = π − x，则 x = π − t，dx = −dt；x = 0 时 t = π，x = π 时 t = 0。 I = ∫_π^0 (π − t) f(sin(π − t)) (−dt) = ∫₀^π (π − t) f(sin t) dt（sin(π − t) = sin t）。 = π∫₀^π f(sin t) dt − ∫₀^π t f(sin t) dt = π∫₀^π f(sin x) dx − I。 移项：2I = π∫₀^π f(sin x) dx，即 I = π/2 ∫₀^π f(sin x) dx。证毕。 （板书核对：板书走 x = t + π 再 u = −t 的路线，可见部分计算正确；开头换元起点与结尾“移项、得证”不在画面内。）

🔑 关键方法

积分里出现 x·f(sin x) 且积分限为 0 到 π：试换元 x = π − t，用 sin(π − t) = sin t 把被积函数变回原形，再与原积分相加消掉含 x 的项。

💡 需要记忆的结论

sin(π − t) = sin t；∫₀^π x f(sin x) dx = π/2 ∫₀^π f(sin x) dx。

🔁 变式题（先闭卷做它）待作答

若 f(x) 在 [0, 1] 上连续，证明 ∫₀^π (π − x) f(sin x) dx = π/2 ∫₀^π f(sin x) dx。
